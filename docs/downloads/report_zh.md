# ViTPose++ / CRCD 实验分析

## 主要判断

模型已经学会训练集上的器械二维关键点定位，但独立操作场景测试存在显著泛化差距。当前结果可作为后续双目/多任务研究的二维基线，尚不能据此认定可稳定用于完整器械姿态估计。

## 实验与选择规则

- 正式训练运行：https://forge.coreweave.com/wandb/xu-wang-23/crcd-vitpose-plus/runs/srjp103z
- ViTPose++-Base：共享编码器与解码器，FBF 五点、PCH 八点输出头，两个新增器械 MoE 专家。
- 输入为给定类别与 GT 框的单目 RGB crop（256×192），不是完整的检测加姿态系统，也没有训练双目视差或时序跟踪。
- 训练 100 epochs / 15,600 steps，batch size 32，BF16。记录的 epoch 耗时合计约 94 分钟。
- train: FBF_1 / PCH_1；val: FBF_2 / PCH_2；test: FBF_E_1 / PCH_E_1。
- 最佳模型仅按验证集两类器械可见点平均误差的宏平均选择：epoch 27 / step 4,212；本次之后才评估独立测试集，没有按测试结果重新选模型。
- 测试集原始 6,669 个标注实例中，520 个因退化框或没有有效关键点被现有加载器排除；实际评估 6,149 个实例（FBF 2,892；PCH 3,257）。训练与验证分别评估 4,986 / 4,344 个实例。

## 收敛与泛化

- epoch 1 → 最优 epoch 27：验证宏平均误差 11.21 → 6.87px。
- epoch 100 的验证宏平均误差为 7.09px，比最佳值高约 3.1%；训练 heatmap MSE 则从最佳 epoch 的 5.56e-5 继续降到 2.02e-5。
- 后期训练收益主要体现在训练拟合，验证集没有同步改善。该曲线支持早停或缩短训练的建议；本实验没有验证具体早停策略的最优参数。
- 最佳模型训练/验证/测试宏平均可见点误差分别为 2.04 / 6.87 / 27.92px。测试误差约为验证的 4.1 倍。
- 各集合的背景、器械朝向、遮挡和关键点可见性分布不同，这与观察到的跨场景性能下降一致；缺少消融时不能把原因归于单一因素。

## 主要误差来源

1. **FBF 钳尖定位不足。** 测试 TipLeft / TipRight 平均误差为 16.91 / 25.47px，PCK@10px 为 37.2% / 20.5%；Center 为 7.78px。当前误差并非只来自器械近端。
2. **PCH 有显著长尾。** 可见点平均误差 37.06px，中位数 7.60px，P90 为 119.68px；22.6% 的可见点误差超过 50px。均值不能概括所有帧，也不能用较好的中位数忽略严重失败。
3. **PCH 的部件表现不一致。** StartHook 的 PCK@10px 为 91.8%；CentralScrew / CentralHook 的平均误差达到 72.38 / 46.51px；TipHook 为 26.37px。典型失败图可见部件定位或骨架结构错配。
4. **遮挡仍然困难。** PCH 遮挡但已标注点的测试平均误差为 51.55px，PCK@10px 22.2%，低于可见点的 59.6%。需要分别报告可见与遮挡结果。
5. **末端八点能力尚未充分覆盖。** 测试 RightScrewTop 仅 18 个可见标注，RightScrewBottom 为 0。后者没有可见点精度可报告；不存在“0 误差”的结论。

## 质量与实现核验

- 最佳 checkpoint 的 epoch、step、选择指标与日志一致，W&B 模型 artifact 已提交。
- 最佳模型重新评估验证集，复现原日志的 6.8733px；逐图坐标统计与评估器指标一致。
- 所有有效可见点都在当前放大后的 crop 范围内（包括扩展到原图之外的区域），裁剪丢失不能解释整体测试退化。
- 原始标注中发现 5 个训练可见点明显超出原图范围、3 个测试可见点稍微越过下边界。应核验标注，原始主指标保留这些点，没有为改善结果而事后删除。
- 钳尖身份互换诊断在可同时观察两个钳尖的测试实例中未发现满足严格阈值的样本；目前不能把误差主要归因于简单左右点互换。
- 划分只保证子集隔离与精确图像哈希去重，原始手术/术者身份隔离仍未核实。视频相邻帧相关，本报告不把点数当作独立样本数来计算置信区间。

## 下一步优先级

1. 核验困难关键点定义与标注（尤其 CentralScrew、CentralHook、FBF 钳尖和越界点），补充独立操作场景训练数据及可见性覆盖。扩大手术序列覆盖比继续增加当前 100-epoch 训练时长更值得优先验证。
2. 建立逐点、按可见性和按序列的评估，报告长尾失败率；对照独立器械模型或普通 ViTPose，判断共享编码器和 MoE 的实际收益。本实验尚不能证明 ViTPose++ 优于这些对照。
3. 以验证集决定早停，并实验更广的旋转、尺度和遮挡增强。提高输入分辨率需要同时适配位置编码；其收益仍需消融验证。
4. 验证二维基线后，引入器械骨架、置信度、双目一致性或时序约束。当前单帧实验没有证据表明它能提升 GMCR 视差，也没有三维/跟踪指标。
